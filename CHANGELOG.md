# 📝 История изменений

## [2.0.0] - 21.11.2025

### 🎨 Революция дизайна иконок

#### Стилизованные контейнеры для иконок
- **До**: Простые SVG иконки без оформления
- **После**: Каждая иконка в премиальном декоративном контейнере

#### Новые возможности:
- ✅ Градиентные фоны для всех контейнеров
- ✅ Многослойные эффекты (::before и ::after псевдоэлементы)
- ✅ Blur-свечение под иконками
- ✅ Box-shadow с градиентными цветами
- ✅ Расширенные hover-эффекты (scale + rotate + glow)
- ✅ Размерная иерархия (от 24px до 100px)

#### Типы стилизованных иконок:
1. **Logo Icon** (40px) - полный градиент + float
2. **Badge Icon** (24px) - полупрозрачный + pulse
3. **Feature Icons** (80px) - двухслойное свечение
4. **Tech Stack Icons** (100px) - тройное свечение ⭐ Самые большие
5. **Role Tab Icons** (40px) - три состояния
6. **Role Feature Icons** (56px) - blur свечение
7. **Scenario Icons** (70px) - enhanced hover
8. **Notification Icon** (48px) - bounce animation

### 🎯 Дизайн-система

#### Градиенты
```css
Основной: rgba(99, 102, 241, X) → rgba(139, 92, 246, X)
Полный: #6366f1 → #8b5cf6 → #ec4899
```

#### Эффекты свечения
- Blur-свечение: filter: blur(10-15px)
- Градиентные оверлеи: opacity 0 → 1
- Drop-shadow для иконок

### 📁 Новые файлы
- `STYLED_ICONS_SYSTEM.md` - полная документация системы

### 🎨 CSS обновления

#### Новые классы-обертки:
- `.logo-icon-wrapper` - 40×40px, полный градиент
- `.badge-icon-wrapper` - 24×24px, с бордером
- `.feature-icon-wrapper` - 80×80px, двухслойный
- `.tech-icon-wrapper` - 100×100px, трехслойный
- Обновлены все существующие icon-классы

#### Hover-эффекты:
```css
transform: translateY(-5px) scale(1.05) rotate(3deg);
box-shadow: многослойные тени;
border-color: усиленный градиент;
```
