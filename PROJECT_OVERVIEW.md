## 🎓 MVP Функционал

### Для Учеников (Students)
```
✓ Дашборд с прогрессом (уроки всего/выполнено)
✓ Домашние задания (фильтры, статусы)
✓ Загрузка решений с файлами
✓ Просмотр оценок и отзывов
✓ Real-time уведомления
✓ Таймлайн активности
```

### Для Преподавателей (Teachers)
```
✓ Профиль с редактированием
✓ Аналитика нагрузки
✓ Создание уроков (клик на слот)
✓ Проверка ДЗ с оценками 0-100
✓ Статистика по ученикам
✓ График оценок
```

### Для Администраторов (Admin)
```
✓ CRM система
✓ Управление учениками
✓ Управление преподавателями
✓ Система абонементов
✓ Управление материалами
✓ Реестр занятий
✓ KPI дашборды
```
