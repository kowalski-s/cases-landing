# EduPlatform MVP - Лендинг

Современный лендинг для демонстрации MVP платформы управления онлайн-школами.

## 🎨 Особенности дизайна

- **Темная тема** с градиентами и неоновыми акцентами
- **Сложные анимации**: плавающие карточки, анимированные графики, интерактивные элементы
- **Адаптивный дизайн** для всех устройств
- **Интерактивные компоненты**: переключение вкладок, hover-эффекты, parallax
- **Оптимизированная производительность** с плавными переходами

## 🚀 Технологии

- **HTML5** - семантическая разметка
- **CSS3** - современные анимации, градиенты, backdrop-filter
- **Vanilla JavaScript** - интерактивность без зависимостей
- **Google Fonts (Inter)** - современная типографика

## 📋 Структура лендинга

1. **Hero секция** - впечатляющий первый экран с анимированными карточками
2. **Возможности** - 6 ключевых фичей платформы
3. **Роли пользователей** - интерактивные вкладки для Ученика, Преподавателя и Администратора
4. **Технологический стек** - демонстрация используемых технологий и архитектуры
5. **Демо-сценарии** - пошаговое описание работы с платформой
6. **Call to Action** - призыв к действию и контактная информация
7. **Footer** - навигация и дополнительная информация

## 🎯 Ключевые возможности MVP

### Для учеников:
- Дашборд с прогрессом обучения
- Управление домашними заданиями
- Загрузка решений с файлами
- Real-time уведомления

### Для преподавателей:
- Управление расписанием
- Проверка домашних заданий с оценками
- Аналитика нагрузки
- Статистика по ученикам

### Для администраторов:
- Полная CRM-система
- Управление учениками и преподавателями
- Система абонементов
- Управление материалами и уроками

## 🎬 Анимации

- **Gradient Orbs** - интерактивные градиентные сферы, следующие за курсором
- **Floating Cards** - плавающие карточки с 3D-эффектом
- **Smooth Scrolling** - плавная прокрутка между секциями
- **Parallax Effect** - эффект параллакса для hero-секции
- **Hover Effects** - трансформации и подсветка при наведении
- **Loading Animations** - скелетоны и прогресс-бары
- **Tilt Effect** - наклон карточек при движении мыши

## 🛠️ Настройка

### Быстрый старт

1. Откройте файл `index.html` в браузере
2. Готово! Лендинг работает без дополнительной настройки

### Локальный сервер (опционально)

Для лучшей работы можно использовать локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js (npx)
npx serve

# VS Code Live Server
# Установите расширение Live Server и нажмите "Go Live"
```

## 📝 Настройка контента

### Изменение контактной информации

В файле `index.html` найдите и замените:

```html
<a href="mailto:your-email@example.com" class="btn btn-primary btn-large">
```

Замените `your-email@example.com` на свой email.

### Изменение цветовой схемы

В файле `styles.css` измените CSS-переменные в `:root`:

```css
:root {
    --accent-primary: #6366f1;  /* Основной акцент */
    --accent-secondary: #8b5cf6; /* Вторичный акцент */
    --accent-tertiary: #ec4899;  /* Третичный акцент */
}
```

### Добавление своих метрик

Измените значения в hero-статистике:

```html
<div class="stat-value">3</div>
<div class="stat-label">Роли пользователей</div>
```
