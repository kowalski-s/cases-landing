# 🎨 Система стилизованных иконок v2.0

## ✨ Концепция дизайна

Вместо простых SVG иконок, теперь **каждая иконка находится в премиальном декоративном контейнере** с:
- Градиентным фоном
- Тенями и свечением
- Многослойными эффектами
- Плавными анимациями
- Hover-состояниями

## 🎨 Градиентная система

### Основной градиент
```css
linear-gradient(135deg, 
  rgba(99, 102, 241, X) 0%,    /* Индиго */
  rgba(139, 92, 246, X) 100%   /* Фиолетовый */
)
```

где `X` - это opacity (от 10% до 25% в зависимости от типа)

### Полный градиент (для логотипа и active состояний)
```css
var(--gradient-primary):
  #6366f1 → #8b5cf6 → #ec4899
```

## ✨ Эффекты и анимации

### 1. **Float Animation**
```css
Применяется к: Logo, Feature Icons, Tech Icons
Длительность: 3-4 секунды
Эффект: Плавное покачивание вверх-вниз
```

### 2. **Pulse Animation**
```css
Применяется к: Badge Icon
Длительность: 2 секунды
Эффект: Пульсация opacity и scale
```

### 3. **Bounce Animation**
```css
Применяется к: Notification Icon
Длительность: 2 секунды
Эффект: Подпрыгивание вверх-вниз
```

### 4. **Icon Glow Animation**
```css
Применяется к: Featured Feature Icon
Длительность: 3 секунды
Эффект: Пульсирующее свечение drop-shadow
```

### 5. **Hover Effects**
Все иконки при hover:
- `transform`: translateY + scale + rotate
- `box-shadow`: усиление теней
- `border-color`: усиление яркости
- Внутренняя иконка: дополнительный scale + filter

## 🔧 Технические детали

### Многослойная структура

```html
<div class="icon-wrapper">         <!-- Контейнер -->
  <svg class="icon">...</svg>      <!-- Иконка -->
</div>
```

### CSS-слои
```css
.icon-wrapper {
  /* Базовый стиль */
  background: градиент;
  border: линия;
  box-shadow: тень;
}

.icon-wrapper::before {
  /* Blur-свечение под контейнером */
  background: градиент;
  filter: blur(10-15px);
  opacity: 0 → 0.15-0.25 при hover;
}

.icon-wrapper::after {
  /* Градиентный оверлей сверху */
  background: linear-gradient(...);
  opacity: 0 → 1 при hover;
}
```

## 💡 Дизайн-принципы

### 1. **Иерархия размеров**
Чем важнее секция → тем крупнее иконки
- Tech Stack (самая важная) → 100px
- Features (ключевые возможности) → 80px
- Остальные секции → 40-70px

### 2. **Градиентная консистентность**
Все иконки используют одну градиентную палитру:
- Индиго (#6366f1)
- Фиолетовый (#8b5cf6)
- Розовый (#ec4899)

### 3. **Многослойность**
Каждый контейнер имеет минимум 3 слоя:
- Основной фон
- Blur-свечение (::before)
- Оверлей (::after или box-shadow)

### 4. **Плавность**
Все transitions и animations:
- Duration: 0.3-0.5s
- Easing: ease / ease-in-out
- GPU-ускорение (transform, opacity)
