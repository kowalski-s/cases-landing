# Инструкция по созданию финальных скриншотов

## Шаги:

### 1. Откройте шаблоны в браузере

Откройте следующие файлы в браузере (просто перетащите файл в окно браузера):
- `template-stats-lk.html` - для объединения статистики и ЛК
- `template-homework-schedule.html` - для объединения ДЗ и расписания  
- `template-notifications.html` - для уведомлений

### 2. Сделайте скриншоты

Для каждого шаблона:
1. Откройте шаблон в браузере
2. Нажмите F12 (открыть DevTools)
3. Нажмите Ctrl+Shift+P (Windows) или Cmd+Shift+P (Mac)
4. Введите "screenshot" и выберите "Capture full size screenshot"
5. Сохраните скриншот с правильным именем

### 3. Сохраните файлы с правильными именами

После создания скриншотов сохраните их в папке `images/` с именами:

- `student-stats-lk.png` - объединенная статистика и ЛК
- `student-homework-schedule.png` - объединенные ДЗ и расписание
- `student-notifications.png` - уведомления

### 4. Альтернативный способ (если нет DevTools)

Можно использовать расширения браузера:
- **Firefox**: Nimbus Screenshot
- **Chrome**: Full Page Screen Capture
- **Edge**: Web Capture (встроенное)

Или просто сделайте скриншот видимой области (Print Screen) и обрежьте до нужного размера.

### 5. Проверка

После сохранения всех трех файлов откройте `index.html` в браузере и проверьте:
- Переключение между скриншотами работает
- Изображения отображаются в темной теме
- Все выглядит гармонично

## Примечания:

- Изображения автоматически обрабатываются CSS-фильтрами для темной темы
- Если нужно скорректировать яркость/контраст, можно изменить фильтры в `styles.css` (класс `.screenshot-image`)
- Рекомендуемое разрешение: минимум 1200px по ширине
