# Быстрый старт: Создание финальных скриншотов

## 📋 Что нужно сделать:

### Шаг 1: Откройте шаблоны

Откройте в браузере (просто перетащите файл):
1. ✅ `template-stats-lk.html` - Статистика + ЛК
2. ✅ `template-homework-schedule.html` - ДЗ + Расписание
3. ⚠️ `template-notifications.html` - Уведомления (нужно добавить скриншот)

### Шаг 2: Сделайте скриншоты

**Способ 1: DevTools (рекомендуется)**
1. Откройте шаблон в браузере
2. Нажмите `F12` (DevTools)
3. Нажмите `Ctrl+Shift+P` (Windows) или `Cmd+Shift+P` (Mac)
4. Введите "screenshot" → выберите "Capture full size screenshot"
5. Сохраните файл

**Способ 2: Расширение браузера**
- Firefox: Nimbus Screenshot
- Chrome: Full Page Screen Capture
- Edge: Web Capture (встроенное, `Ctrl+Shift+S`)

**Способ 3: Print Screen**
- Сделайте скриншот видимой области
- Обрежьте до нужного размера в любом редакторе

### Шаг 3: Сохраните с правильными именами

Сохраните скриншоты в папке `images/` с именами:

```
images/
  ├── student-stats-lk.png          ← Статистика + ЛК
  ├── student-homework-schedule.png ← ДЗ + Расписание
  └── student-notifications.png     ← Уведомления
```

### Шаг 4: Проверьте результат

Откройте `index.html` в браузере и проверьте:
- ✅ Переключение между скриншотами работает
- ✅ Изображения отображаются в темной теме
- ✅ Все выглядит гармонично

## 🎨 Что делают шаблоны:

- **Темная тема**: Автоматически применяется к скриншотам
- **Объединение**: Два скриншота размещаются рядом
- **Стилизация**: Фиолетовые акценты в стиле лендинга
- **Адаптивность**: На мобильных устройствах скриншоты располагаются вертикально

## ⚠️ Важно:

- Файл с уведомлениями нужно добавить отдельно (если у вас есть скриншот)
- Все изображения автоматически обрабатываются CSS-фильтрами
- Рекомендуемое разрешение: минимум 1200px по ширине
