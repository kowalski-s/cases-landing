# Скриншоты для лендинга

## Структура изображений

Для блока "Персонализированный опыт для каждой роли" (роль "Ученик") необходимо добавить 3 изображения:

### 1. `student-stats-lk.png`
**Композиция: Статистика + Личный кабинет**

Объединенный скриншот, показывающий:
- **Статистика ученика:** Карточки со статистикой (уроки, домашние задания, средняя оценка, активность) и графики (посещаемость, оценки)
- **Личный кабинет:** Профиль ученика, абонемент, ближайший урок, прогресс

### 2. `student-homework-schedule.png`
**Композиция: ДЗ + Расписание**

Объединенный скриншот, показывающий:
- **Домашние задания:** Список заданий с фильтрами (Все/Невыполненные/Проверенные), статусы (ожидает проверки, проверено с оценкой)
- **Расписание:** Список занятий с фильтрами по преподавателю, классу, статусу

### 3. `student-notifications.png`
**Уведомления**

Скриншот страницы уведомлений:
- Список всех уведомлений
- Фильтры (Все/Непрочитанные)
- Статусы прочитанных/непрочитанных уведомлений

## Требования к изображениям

- **Формат:** PNG (рекомендуется) или JPG
- **Разрешение:** Минимум 1200px по ширине (для качественного отображения)
- **Соотношение сторон:** Предпочтительно 16:9 или 4:3
- **Размер файла:** Оптимизировать для веба (рекомендуется < 500KB на изображение)

## Обработка изображений

Изображения будут автоматически обработаны CSS-фильтрами для темной темы:
- Затемнение (brightness: 0.7)
- Увеличение контраста (contrast: 1.25)
- Легкая инверсия цветов (invert: 0.12)
- Фиолетовый оттенок для соответствия стилю лендинга

## Размещение файлов

Поместите все 3 изображения в папку `images/` в корне проекта:
```
cases-landing/
  └── images/
      ├── student-stats-lk.png
      ├── student-homework-schedule.png
      └── student-notifications.png
```

## Проверка

После добавления изображений:
1. Откройте `index.html` в браузере
2. Перейдите к блоку "Персонализированный опыт для каждой роли"
3. Выберите роль "Ученик"
4. Проверьте переключение между тремя скриншотами через кнопки навигации
